ATUALIZAÇÃO LOCAL
1. Antes de tudo, abra sua versão atual e use SISTEMA > EXPORTAR SAVE.
2. Guarde o arquivo JSON.
3. Extraia este ZIP.
4. Copie index.html, style.css, app.js, manifest.json, service-worker.js e a pasta icons para a mesma pasta do Project Arise.
5. Substitua os arquivos existentes.
6. Abra index.html.
7. A Alpha 1.6 migra automaticamente saves da Alpha 1.5 e versões anteriores.
8. Se o progresso não aparecer, use SISTEMA > IMPORTAR SAVE e selecione o JSON exportado.
