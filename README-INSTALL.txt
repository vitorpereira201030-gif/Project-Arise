PROJECT ARISE — ALPHA 1.4 • ASCENSION UPDATE

ARQUIVOS
- index.html
- style.css
- app.js
- manifest.json
- service-worker.js
- icons/

ATUALIZAÇÃO LOCAL (PC)
1. Faça backup da pasta Alpha 1.3.
2. No Project Arise 1.3, abra SISTEMA > EXPORTAR SAVE e guarde o JSON.
3. Substitua os arquivos antigos pelos arquivos desta pasta.
4. Abra o mesmo index.html. O save local da Alpha 1.3 é migrado automaticamente para 1.4.
5. Se necessário, use SISTEMA > IMPORTAR SAVE e selecione o JSON exportado.

ATUALIZAÇÃO NO GITHUB PAGES
1. Exporte o save no celular antes de atualizar.
2. No repositório do Project Arise, substitua index.html, style.css, app.js, manifest.json, service-worker.js e a pasta icons pelos arquivos desta versão.
3. Faça commit das alterações no branch publicado pelo Pages (normalmente main / root).
4. Espere a publicação terminar e abra o site novamente.
5. A Alpha 1.4 tenta migrar automaticamente o save 1.3 do mesmo navegador/origem.
6. Se o save não aparecer, use SISTEMA > IMPORTAR SAVE com seu JSON de backup.

IMPORTANTE
- Não apague o repositório nem troque o endereço do site se quiser manter o localStorage automaticamente.
- O backup JSON é a proteção mais segura antes de cada atualização.
- O cooldown de 12h é apenas um bloqueio mínimo do sistema, não uma obrigação de treinar assim que liberar.
