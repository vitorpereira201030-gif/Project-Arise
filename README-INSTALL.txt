PROJECT ARISE — ALPHA 1.3 • BODY SYNC UPDATE

ATUALIZAÇÃO NO PC
1. Faça backup da pasta Alpha 1.2.
2. Copie TODOS os arquivos e a pasta icons deste pacote para a pasta Project-Arise atual.
3. Substitua os arquivos antigos.
4. Abra index.html. O save da 1.2 será migrado automaticamente.
5. Para zerar os testes: SISTEMA > RESETAR PROGRESSO.

CELULAR / PWA
- A interface funciona no navegador do celular.
- Para instalar como aplicativo e ter modo offline, hospede estes arquivos em um endereço HTTPS.
- Depois, abra o endereço no Chrome/Edge do celular e escolha Instalar app / Adicionar à tela inicial.
- Abrir index.html diretamente pelo gerenciador de arquivos não ativa service worker/PWA.

REGRAS DE TEMPO
- Após concluir as 4 missões: cooldown de 12h.
- Streak: próxima quest deve ser concluída em até 36h da anterior.
- 12h é o mínimo técnico, não uma obrigação. Se o corpo não estiver recuperado, espere mais.
