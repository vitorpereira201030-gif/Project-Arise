ANTES DE QUALQUER COISA
1. Abra sua Alpha 1.4 atual no CELULAR.
2. Entre em ⚙ SISTEMA.
3. Toque em EXPORTAR SAVE.
4. Confirme que um arquivo project-arise-save-AAAA-MM-DD.json foi salvo.
5. Guarde uma segunda cópia, se possível.

SUBSTITUINDO A ALPHA 1.4 NO GITHUB
1. No PC, extraia Project-Arise-Alpha-1.5-Manifestation-Update.zip.
2. Abra a pasta Project-Arise-Alpha-1.5.
3. Entre no MESMO repositório do GitHub que hospeda seu Project Arise.
4. Na raiz do repositório, use Add file > Upload files.
5. Envie/substitua:
   - index.html
   - style.css
   - app.js
   - manifest.json
   - service-worker.js
   - README-INSTALL.txt
   - GITHUB-UPDATE-GUIDE.txt
   - CHANGELOG-1.5.txt
   - pasta icons/
6. Confirme o commit no branch que o GitHub Pages já publica (normalmente main).
7. Não crie uma pasta Project-Arise-Alpha-1.5 dentro do repositório se hoje index.html fica na raiz.
8. Aguarde o GitHub Pages publicar a alteração.
9. Abra o endereço normal do seu Project Arise no navegador e confira o cabeçalho:
   Alpha 1.5 • Manifestation Update

NO CELULAR / PWA

2. Abra primeiro o endereço do GitHub Pages no navegador.
3. Atualize a página.
4. Feche completamente a PWA Project Arise.
5. Abra novamente pelo ícone da tela inicial.
6. A versão nova usa um cache diferente do service worker e deve substituir a anterior.
