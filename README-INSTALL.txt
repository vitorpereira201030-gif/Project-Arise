ARQUIVOS
- index.html

ANTES DE ATUALIZAR
1. Abra a Alpha 1.4 no dispositivo que possui seu progresso real.
2. Entre em SISTEMA > EXPORTAR SAVE.
3. Guarde o arquivo JSON em Downloads e, se possível, faça uma segunda cópia.

ATUALIZAÇÃO LOCAL (PC)
1. Faça backup da pasta atual.
2. Substitua index.html, style.css, app.js, manifest.json, service-worker.js e icons/ pelos arquivos da Alpha 1.5.
3. Abra o mesmo index.html/endereço usado antes.
4. A Alpha 1.5 migra automaticamente saves da Alpha 1.4 quando a origem/localStorage é a mesma.
5. Se necessário, use SISTEMA > IMPORTAR SAVE e selecione o JSON exportado.

ATUALIZAÇÃO NO GITHUB PAGES
1. Exporte o save no celular ANTES de alterar o GitHub.
2. Abra o mesmo repositório que atualmente hospeda o Project Arise.
3. Na raiz do repositório, substitua index.html, style.css, app.js, manifest.json e service-worker.js; substitua também a pasta icons/ se houver mudança nos ícones.
4. Faça commit no branch publicado pelo Pages (normalmente main, pasta /(root)).
5. Aguarde o deploy terminar.
6. Abra o endereço normal do Project Arise e confirme que o cabeçalho mostra Alpha 1.5 • Manifestation Update.
7. Se a PWA instalada ainda mostrar a versão antiga, abra o site pelo navegador, atualize a página, feche completamente o app e abra novamente. Evite limpar os dados do site antes de confirmar seu backup.
8. A Alpha 1.5 tenta migrar o save Alpha 1.4 automaticamente. Se não aparecer, use SISTEMA > IMPORTAR SAVE.

IMPORTANTE
- Não apague o repositório nem troque o endereço do site se quiser preservar o localStorage automaticamente.
