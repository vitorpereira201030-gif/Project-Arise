PROJECT ARISE 2.0 — AWAKENING SYSTEM

PROJECT ARISE ALPHA 1.7 — COMO ATUALIZAR NO GITHUB PAGES

ANTES DE TUDO
1. Abra sua versão atual do Project Arise.
2. Vá em SISTEMA > EXPORTAR SAVE.
3. Confirme que o arquivo .json foi salvo em Downloads.
4. Guarde uma cópia. Não limpe cache/dados do site antes da atualização.

ATUALIZAÇÃO
1. Extraia o ZIP da Alpha 1.7 no PC.
2. Abra o MESMO repositório do GitHub que já publica seu Project Arise.
3. Na raiz do repositório use Add file > Upload files.
4. Substitua:
   index.html
   style.css
   app.js
   manifest.json
   service-worker.js
   icons/
5. Faça o commit. Sugestão: Project Arise Alpha 1.7 - Cinematic Identity Update
6. Não altere Settings > Pages se já estiver funcionando em main /(root).
7. Aguarde a publicação.
8. Abra o endereço do GitHub Pages pelo navegador e atualize.
9. Feche completamente a PWA instalada e abra novamente.
10. O topo deve mostrar Alpha 1.7 • Cinematic Identity Update.

SAVE
- A Alpha 1.7 procura projectAriseAlpha16 e versões anteriores e migra automaticamente.
- Se aparecer Level 1 ou algo faltar: NÃO resete.
- Vá em SISTEMA > IMPORTAR SAVE e selecione o JSON exportado antes da atualização.

CACHE
- O service worker usa um cache novo para a 1.7.
- Evite usar "Limpar dados do site" como primeira tentativa, pois isso pode apagar o save local.
